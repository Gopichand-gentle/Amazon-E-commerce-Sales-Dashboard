# Amazon E-Commerce Sales Analysis Dashboard

## Project Overview

Developed an interactive E-Commerce Sales Analysis Dashboard using Microsoft Power BI to evaluate sales performance, order trends, product performance, category performance, brand performance, and device-wise order distribution.

The project involved data cleaning, data transformation, data modeling, DAX calculations, KPI development, and interactive data visualization to convert raw e-commerce data into actionable business insights.

## Business Objective

The primary objective of this project is to analyze e-commerce sales data and provide a centralized business intelligence dashboard for monitoring key performance indicators and identifying sales trends.

The analysis focuses on:

- Evaluating overall sales and order performance
- Analyzing sales by product category and sub-category
- Identifying top-performing brands and products
- Analyzing device-wise order distribution
- Monitoring key performance indicators (KPIs)
- Identifying trends and patterns in sales performance
- Supporting data-driven business decision-making

## Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data extraction, cleaning, and transformation
- **DAX (Data Analysis Expressions)** – Measures and calculated metrics
- **Data Modeling** – Structuring data for analytical reporting
- **Data Visualization** – Interactive charts, KPI cards, tables, and filters

## Key Dashboard Features

- Interactive sales and order KPI dashboard
- Sales performance analysis
- Category-wise sales analysis
- Sub-category-wise sales analysis
- Brand-wise sales analysis
- Device-wise order analysis
- Product-level performance analysis
- Interactive slicers and filters
- Dynamic data visualizations
- Business-focused reporting

## Data Analysis & Insights

The dashboard enables analysis of e-commerce performance across multiple business dimensions, including products, categories, sub-categories, brands, and devices.

It helps users identify high-performing products and categories, compare sales performance, understand order distribution, and explore patterns within the underlying sales data.
